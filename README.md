Українською про LLM майже нічого немає. Є розрізнені переклади статей і є англомовні
курси, які починаються з математики і закінчуються ноутбуком у Colab. Ні те, ні інше не
відповідає на питання, яке насправді стоїть перед розробником: **як зробити на LLM
систему, яка працює в продакшні і яку не соромно показати.**

`LLM Master UA` — це послідовний шлях: **базові поняття → виклик моделі → RAG → агенти →
донавчання і деплой → Transformer → проєкти й співбесіди.** Кожен розділ пояснює не лише
«що це таке», а й чому зроблено саме так, як це впровадити, як діагностувати поломку і як
про це розповісти на співбесіді.

## Чим ця версія відрізняється від оригіналу

Це не просто переклад. Порівняно з [оригінальним репозиторієм](#джерело):

- **Прибрано те, що протухає і не стосується нас** — стрічка новин про релізи моделей,
  розбори китайського ринку праці, матеріали про обхід регіональних блокувань.
- **Єдина термінологія** — [глосарій](GLOSSARY.md) на ~120 термінів, від якого не
  відхиляється жодна стаття. Англійські терміни, які реально вживають розробники,
  залишено англійськими.
- **Робочий код** — приклади з розділу Transformer зібрано в [`code/`](code/README.md)
  як файли, які реально запускаються (перевірено на Python 3.14 + numpy).
- **Локальний контекст** — три власні статті замість китайських розділів:
  [скільки коштує українська мова в токенах](docs/llm/intro/ukrainian_tokens.md) (власні
  заміри на паралельному корпусі), [доступ до API з України](docs/llm/intro/api_access_ukraine.md)
  і [Акт ЄС про штучний інтелект](docs/llm/intro/eu_ai_act.md) замість китайського регулювання.
- **Картинки локально** — усі 466 ілюстрацій лежать у репозиторії, а не хотлінкаються
  з китайського CDN, який може зникнути.

## Як цим користуватися

1. **Вперше** — відкрийте [повний шлях навчання](docs/roadmap/README.md) і заходьте з того
   етапу, що відповідає вашому рівню. Не читайте індекс підряд.
2. **Робите проєкт** — ідіть у відповідну [тему](docs/topics/README.md) і закривайте
   конкретну прогалину.
3. **Готуєтесь до співбесіди** — спершу теми, потім [шлях до співбесіди](docs/roadmap/interview.md).

Для власних замірів токенізації та перевірки посилань є два скрипти:

```bash
npm install
npm run check    # китайські залишки й биті лінки по всьому репозиторію
npm run tokens   # скільки токенів коштує українська: власний паралельний корпус
```

## Кому підійде

Розробникам із досвідом, які заходять у LLM-розробку; інженерам, що вже будують RAG,
агентів або AI-бекенд; тим, хто хоче закрити прогалини в теорії та продакшн-практиці.

Це **не** курс з дослідження архітектур і не посібник із навчання базових моделей. Якщо ваша
мета — математика й нові архітектури, беріть цей репозиторій як інженерне доповнення.
