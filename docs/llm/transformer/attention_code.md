Спершу пригадаймо сказане раніше:

**Attention ставить питання «на які слова в реченні поточному слову треба зважати передусім?»**

Наприклад, таке речення:

> Олег каже, що вчора нарешті розібрався в Transformer

Коли модель обробляє слово «він» (у складнішому варіанті речення), їй треба визначити, на кого воно вказує.
Тоді позиція цього слова має «подивитися» на все речення й виявити, що:

- позиція «Олег» має найвищий зв'язок
- позиції «вчора», «розібрався» теж чогось варті
- службові слова на кшталт «що» мають дуже низький зв'язок

Attention робить ось що:

1. **Обчислює зв'язок:** оцінки зв'язку поточного слова з усіма словами
2. **Нормалізує:** перетворює оцінки на розподіл імовірностей (сума дорівнює 1)
3. **Зважено збирає:** за цими ймовірностями витягує інформацію

Ці три кроки і є всією суттю attention.

Продемонструємо на дуже простому реченні:

> **Удалині росте яблуня**

Припустімо, що після embedding кожен токен стає чотиривимірним вектором (у реальних моделях зазвичай 512 або 1024 виміри, тут беремо 4 для зручності розуміння).

### Який вигляд має вхід?

```python
import numpy as np

# Припустімо, вхідна послідовність: Удалині росте яблуня (уже після embedding)
# Довжина послідовності L=7, розмірність embedding d_model=4
sentence = "Удалині росте яблуня"
L = 7  # довжина послідовності
d_model = 4  # розмірність embedding

# Імітуємо вхід після embedding (у реальності це вихід шару embedding)
np.random.seed(42)
X = np.random.randn(L, d_model)

print("Форма вхідної матриці X:", X.shape)
print("Вміст:\n", X[:3, :])  # друкуємо лише перші 3 токени
```

**Вивід:**
```
Форма вхідної матриці X: (7, 4)
Вміст:
 [[ 0.49671415 -0.1382643   0.64768854  1.52302986]
 [-0.23415337 -0.23413696  1.57921282  0.76743473]
 [-0.46947439  0.54256004 -0.46341769 -0.46572975]]
```

Як бачимо, вхід — це матриця `(7, 4)`:
- 7 рядків: 7 токенів
- 4 стовпці: вектор embedding кожного токена має 4 виміри

## Крок 1: обчислюємо Q, K, V

**Ще раз пригадаймо, що таке Q, K, V.**

Простими словами:
- **Q (Query):** хто я? про що я хочу спитати?
- **K (Key):** хто ти? яку інформацію ти можеш дати?
- **V (Value):** конкретний вміст, який я передаю

Усі три отримуються лінійним перетворенням входу X:

```python
# Визначаємо три матриці ваг (у реальності це навчані параметри)
d_k = 4  # розмірність Q і K
d_v = 4  # розмірність V

W_Q = np.random.randn(d_model, d_k)
W_K = np.random.randn(d_model, d_k)
W_V = np.random.randn(d_model, d_v)

print("\nФорми матриць ваг:")
print("W_Q:", W_Q.shape)  # (4, 4)
print("W_K:", W_K.shape)  # (4, 4)
print("W_V:", W_V.shape)  # (4, 4)

# Обчислюємо Q, K, V
Q = np.dot(X, W_Q)  # (7, 4) @ (4, 4) = (7, 4)
K = np.dot(X, W_K)  # (7, 4) @ (4, 4) = (7, 4)
V = np.dot(X, W_V)  # (7, 4) @ (4, 4) = (7, 4)

print("\nФорми Q, K, V:")
print("Q:", Q.shape)  # (7, 4)
print("K:", K.shape)  # (7, 4)
print("V:", V.shape)  # (7, 4)
```

**Вивід:**
```
Форми матриць ваг:
W_Q: (4, 4)
W_K: (4, 4)
W_V: (4, 4)

Форми Q, K, V:
Q: (7, 4)
K: (7, 4)
V: (7, 4)
```

**Навіщо так робити?**

Бо той самий вхід у різних ролях має зважати на різні ознаки:
- як Query він зосереджений на тому, «яка інформація мені потрібна»
- як Key — на тому, «яку інформацію я можу дати»
- як Value він є «тим вмістом, який я фактично передаю»

Різні матриці ваг дозволяють моделі засвоїти ці три різні «погляди».

## Крок 2: обчислюємо оцінки уваги

Маючи Q і K, можна обчислити «зв'язок».

**Як саме?**

Множенням матриць: Q множимо на транспоновану K.

```python
# Обчислюємо матрицю оцінок уваги
# Q @ K^T: (7, 4) @ (4, 7) = (7, 7)
attention_scores = np.dot(Q, K.T)

print("\nФорма матриці оцінок уваги:", attention_scores.shape)  # (7, 7)
print("Вміст:\n", attention_scores[:3, :3])  # друкуємо фрагмент 3x3
```

**Вивід:**
```
Форма матриці оцінок уваги: (7, 7)
Вміст:
 [[-1.49844942 -3.92493737  1.43255654]
 [-4.2929274  -9.39827614  4.30121785]
 [-2.3579738   0.37174342  1.46417744]]
```

**Що означає ця матриця (7, 7)?**

- кожен рядок відповідає одному токену
- кожен стовпець теж відповідає одному токену
- значення в позиції `[i, j]` показує, наскільки i-й токен зважає на j-й

Наприклад, `attention_scores[2, 0]` — це оцінка, з якою третій токен зважає на перший.

## Крок 3: масштабування (Scaled)

Це ключовий невеликий прийом зі статті про attention.

**Навіщо ділити на $√d_k$?**

```python
# Масштабування: ділимо на sqrt(d_k)
scaled_scores = attention_scores / np.sqrt(d_k)

print("\nФорма оцінок після масштабування:", scaled_scores.shape)  # (7, 7)
print("Діапазон значень до масштабування:", attention_scores.min(), "до", attention_scores.max())
print("Діапазон значень після масштабування:", scaled_scores.min(), "до", scaled_scores.max())
```

**Вивід:**
```
Форма оцінок після масштабування: (7, 7)
Діапазон значень до масштабування: -17.4478031839568 до 14.764287273744408
Діапазон значень після масштабування: -8.7239015919784 до 7.382143636872204
```

**Навіщо це потрібно?**

Коли $d_k$ великий (скажімо, 512), значення $Q·K^T$ стають дуже великими, і під час softmax:
- великі значення після softmax наближаються до 1
- малі — до 0
- градієнт стає дуже малим, і навчати модель складно

Ділення на $√d_k$ утримує діапазон значень у розумних межах.

## Крок 4: нормалізація softmax

Тепер перетворюємо оцінки на ймовірності:

```python
def softmax(x):
    """softmax по кожному рядку"""
    exp_x = np.exp(x - np.max(x, axis=-1, keepdims=True))  # віднімаємо максимум, щоб уникнути переповнення
    return exp_x / np.sum(exp_x, axis=-1, keepdims=True)

# softmax по кожному рядку
attention_weights = softmax(scaled_scores)

print("\nФорма ваг уваги:", attention_weights.shape)  # (7, 7)
print("Розподіл уваги першого токена:\n", attention_weights[0, :])
print("Сума кожного рядка:", np.sum(attention_weights, axis=-1))  # сума кожного рядка дорівнює 1
```

**Вивід:**
```
Форма ваг уваги: (7, 7)
Розподіл уваги першого токена:
 [0.04115936 0.01223386 0.17820851 0.16625512 0.21927912 0.14523322 0.23763083]
Сума кожного рядка: [1. 1. 1. 1. 1. 1. 1.]
```

**Що означає ця матриця:**

- кожен рядок — це розподіл імовірностей із сумою 1
- i-й рядок показує, скільки уваги i-й токен має віддати кожній позиції
- що більше значення, то важливіша позиція

## Крок 5: зважене підсумовування

Останній крок: зважуємо Value вагами уваги.

```python
# Зважуємо V вагами уваги
# (7, 7) @ (7, 4) = (7, 4)
output = np.dot(attention_weights, V)

print("\nФорма підсумкового виходу:", output.shape)  # (7, 4)
print("Форма входу:", X.shape)  # (7, 4)
print("\nПерші 3 токени виходу:\n", output[:3, :])
```

**Вивід:**
```
Форма підсумкового виходу: (7, 4)
Форма входу: (7, 4)

Перші 3 токени виходу:
```

**Зверніть увагу:**

- форма виходу повністю збігається з формою входу: `(7, 4)`
- але вектор кожного токена вже містить інформацію інших токенів
- вагами цього змішування є щойно обчислений розподіл уваги

## Повний код

```python
import numpy as np

def scaled_dot_product_attention(Q, K, V):
    """
    Найбазовіший масштабований скалярний добуток уваги

    Параметри:
        Q: матриця Query, shape (L, d_k)
        K: матриця Key, shape (L, d_k)
        V: матриця Value, shape (L, d_v)

    Повертає:
        output: вихідна матриця, shape (L, d_v)
        attention_weights: ваги уваги, shape (L, L)
    """
    d_k = Q.shape[-1]

    # 1. Обчислюємо оцінки уваги: Q @ K^T
    scores = np.dot(Q, K.T)
    print(f"Крок 1 - оцінки уваги: {scores.shape}")

    # 2. Масштабування
    scaled_scores = scores / np.sqrt(d_k)
    print(f"Крок 2 - після масштабування: {scaled_scores.shape}")

    # 3. Softmax
    exp_scores = np.exp(scaled_scores - np.max(scaled_scores, axis=-1, keepdims=True))
    attention_weights = exp_scores / np.sum(exp_scores, axis=-1, keepdims=True)
    print(f"Крок 3 - ваги уваги: {attention_weights.shape}")

    # 4. Зважене підсумовування
    output = np.dot(attention_weights, V)
    print(f"Крок 4 - підсумковий вихід: {output.shape}")

    return output, attention_weights

# Приклад використання
if __name__ == "__main__":
    # Налаштування входу
    L = 7  # довжина послідовності
    d_model = 4  # розмірність embedding

    np.random.seed(42)

    # 1. Вхід
    X = np.random.randn(L, d_model)
    print(f"Вхід X: {X.shape}\n")

    # 2. Генеруємо Q, K, V
    W_Q = np.random.randn(d_model, d_model)
    W_K = np.random.randn(d_model, d_model)
    W_V = np.random.randn(d_model, d_model)

    Q = np.dot(X, W_Q)
    K = np.dot(X, W_K)
    V = np.dot(X, W_V)

    print(f"Q: {Q.shape}")
    print(f"K: {K.shape}")
    print(f"V: {V.shape}\n")

    # 3. Обчислюємо attention
    print("=== Починаємо обчислення attention ===")
    output, weights = scaled_dot_product_attention(Q, K, V)

    print(f"\nФорма підсумкового виходу: {output.shape}")
    print(f"Форма входу: {X.shape}")
    print(f"Форма не змінилася: {output.shape == X.shape}")
```

**Вивід під час запуску:**
```
Вхід X: (7, 4)

Q: (7, 4)
K: (7, 4)
V: (7, 4)

=== Починаємо обчислення attention ===
Крок 1 - оцінки уваги: (7, 7)
Крок 2 - після масштабування: (7, 7)
Крок 3 - ваги уваги: (7, 7)
Крок 4 - підсумковий вихід: (7, 4)

Форма підсумкового виходу: (7, 4)
Форма входу: (7, 4)
Форма не змінилася: True
```

**Ключові спостереження:**

1. **Форми входу й виходу збігаються:** `(L, d_model)` → `(L, d_model)`
2. **Посередині з'являється (L, L):** це матриця уваги, яка фіксує, наскільки кожна позиція зважає на інші
3. **Множення матриць — це основа:** увесь процес складається з трьох матричних множень

---

У цій статті ми написали з нуля найбазовіший механізм attention:

1. **Вхід → Q, K, V:** лінійним перетворенням отримуємо три «погляди»
2. **Q @ K^T:** обчислюємо оцінки зв'язку
3. **Масштабування:** ділимо на √d_k, щоб стабілізувати значення
4. **Softmax:** перетворюємо на розподіл імовірностей
5. **Зважене підсумовування:** вагами збираємо інформацію з V

**Суть одним реченням:**

> **Дати кожній позиції змогу «побачити» інші позиції й зібрати звідти релевантну інформацію.**
