# Скрипти

| Скрипт | Навіщо |
|---|---|
| `check.mjs` | Перевіряє весь репозиторій: залишки китайської, сторонні символи, биті лінки. `npm run check` |
| `tokens-ua.mjs` | Заміряє, скільки токенів коштує українська, на паралельному корпусі з git-історії. `npm run tokens` |
| `extract-code.mjs` | Збирає код зі статей розділу «Пишемо Transformer з нуля» у запускні файли в `code/`. |
| `verify-*.mjs` | Одноразові перевірки числових прикладів у статтях про Transformer: незалежні реалізації на JS, які мають давати ті самі числа, що й код у тексті. Запускаються без аргументів. |
| `numpy-rng.mjs` | Відтворює `np.random.seed(42)` на JS — потрібен скриптам `verify-*`, щоб порівнювати числа один в один зі статтями. |

Скрипти писалися під цей репозиторій і не претендують на універсальність.
